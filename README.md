# Herbstsonntag 🍂

A lowkey autumn Sunday mod for Claude Code: warm oat-and-pumpkin colours (chestnut and lamplight in dark mode), flat, graphic-style autumn leaves floating slowly down the window (a squirrel peeks up now and then beside a pumpkin, across from a steaming mug of hot chocolate), an optional fireside ambience, gentle mood lines in the status bar, a tea-break nudge every 50 minutes, and a `/herbst` command that suggests a tiny three-step Sunday plan (German by default, `/herbst en` for English).

The colours, leaves and sound show in the Claude desktop and mobile apps; the status line, tea nudge and `/herbst` also work in the terminal. Turn the sound on with the speaker icon in the session's title bar.

## Install

At the prompt of a terminal session:

```
/plugin install herbstsonntag --marketplace aliciabankhofer/herbstsonntag
```

Answer `y` to add the marketplace, then pick a scope (user is the default).

From a shell:

```bash
claude plugin install herbstsonntag --marketplace aliciabankhofer/herbstsonntag
```

In the desktop app: click + next to the prompt box, then Plugins, Add marketplace with `aliciabankhofer/herbstsonntag`, then Add plugin.

No account or setup needed to install: the repository is public.
